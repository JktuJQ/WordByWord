# Мининабор для проверки диаризации

Два примера из [mexus/ru-book-mix-10h](https://huggingface.co/datasets/mexus/ru-book-mix-10h), ревизия `18655c48833c5acfcd868a36eb38465712d15f1c`, скачаны 6 ноября 2026 года. Файлы извлечены без изменений из `data/shard-0000.tar` и `data/shard-0001.tar` соответственно.

| Запись | Длительность | Говорящих | Аудио |
| --- | --- | --- | --- |
| `rec_0055` | 60 с | 2 | FLAC, 16 кГц, моно, 16 бит |
| `rec_0273` | 60 с | 3 | FLAC, 16 кГц, моно, 16 бит |

Для каждой записи:

- `.flac` — аудио для импорта и обработки;
- `.rttm` — эталонные интервалы говорящих;
- `.json` — исходные метаданные: участники, длительность, доля пересекающейся речи;
- `SHA256SUMS` — контрольные суммы этих файлов, проверка: `sha256sum -c SHA256SUMS` из этой папки.

В строке RTTM `SPEAKER rec_0055 1 0.387 4.768 <NA> <NA> spk0 <NA> <NA>` значения `0.387` и `4.768` — начало и **длительность в секундах**, а не начало и конец. В контрактах приложения используются миллисекунды: для этой строки начало — 387, конец — 5155. ID говорящих локальны для записи. При сравнении результатов нужно сопоставлять говорящих по интервалам, а не требовать буквального совпадения ID модели с `spk0`/`spk1`.

Это синтетически смонтированные фрагменты настоящей русской речи из аудиокниг с добавленным шумом и пересечениями голосов. Они подходят для первой проверки конвейера, но не заменяют естественный разговор. Эталонного текста реплик здесь нет — WER по этим файлам без дополнительной транскрипции не измерить. Не использовать для обучения моделей.

Формат и длительность проверены через ffprobe; диаризация на этих записях нами пока не запускалась. Полная исходная карточка датасета сохранена в [SOURCE.md](SOURCE.md).
