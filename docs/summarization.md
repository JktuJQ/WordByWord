# Краткое содержание

Кнопка «Подытожить» открывает экран выбора ключевых выдержек готовой стенограммы.
Текст выводится дословно из стенограммы; результат можно выделить и скопировать.
Исходная стенограмма и внешний JSON не меняются.

## Модель

Qwen3-0.6B INT4 no-think работает на CPU через LiteRT-LM Android 0.17.1.
Источник: [litert-community/Qwen3-0.6B-int4](https://huggingface.co/litert-community/Qwen3-0.6B-int4).
Ревизия — `56621f0115eba5781051ef9714c06e16e6d40c0b`.
Файл — `qwen3_0.6b_nothink_q4_block32_ekv1280.litertlm`, 347251840 байт.
SHA-256 — `2df6821ec12702dafd33915e7a1a1adc7c4b053f3672fd9555dfaf3a114c4139`.
Лицензия Apache-2.0 включена в `assets/summary/LICENSE`.

Задача `prepareSummaryModel` в `app/gradle/models.gradle` скачивает веса с проверкой суммы в `app/build/generated/summaryAssets/`.
Модель включается в APK и при первом запуске функции копируется в приватный каталог без резервного копирования.
Интернет во время обработки не используется.

## Выполнение

`SummaryRunner` хранит состояние операции в Application и использует последовательный исполнитель обработки.
Одновременная работа суммаризации и аудиоконвейера блокируется контроллером.
Модель загружается один раз на операцию и закрывается после завершения, отмены или ошибки.

Текст обрабатывается частями до 512 байт UTF-8, с предпочтением границ предложений и реплик.
Каждая часть содержит до 16 нумерованных фрагментов.
Модель выбирает до трёх номеров; приложение проверяет ответ и выводит соответствующие исходные фрагменты в их порядке.
Контекст — 1280 токенов, ответ ограничен 32 токенами.
Экран показывает текущую часть и позволяет отменить операцию.

Готовый результат атомарно сохраняется в `summary.json` рядом с записью.
Ключ учитывает исходный текст, имена участников и версию алгоритма.
Ошибка или отмена не сохраняют частичный ответ.
После завершения процесса незавершённая операция не возобновляется автоматически.

## Ограничения

Выбор выдержек может пропустить важное и потерять связи между частями.
Это не свободно написанное резюме и не исправление ошибок ASR.
Размер весов не равен памяти процесса; помимо APK нужна приватная копия модели.
Успешная генерация на эмуляторе не заменяет проверку качества и ресурсов на телефоне.
