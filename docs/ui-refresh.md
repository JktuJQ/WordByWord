# Интерфейс «Слово в слово»

Обновление на ветке `feature/orange-ui-refresh`, 7 ноября 2026. Ветка содержит интеграцию GitHub main `503d623`.

## Навигация и библиотека

Главная отделена от библиотеки. На главной — процедурная сфера, центрированный заголовок «Слово в слово» и две кнопки: запись и импорт. Верхняя кнопка с названием удалена; переход на главную — в нижней навигации. На остальных экранах сверху остаются только контекстные действия.

В библиотеке доступны поиск по названию, очистка строки, выход из поиска отдельной стрелкой назад, выбор через кнопку или долгое нажатие и выбор всех записей. Выбор сохраняется при повороте. При открытом поиске лупа скрывается. Из стенограммы, открытой через поиск, стрелка возвращает к результатам.

## Оформление

Нейтральный белый фон, серые второстепенные элементы, яркий оранжевый `#FF6A00` для основных действий и иконки приложения. Тёмный текст на оранжевых кнопках сохраняет читаемость. Подписи участников без плашек переменной ширины; верхние элементы переименования имеют одинаковую ширину 152 dp, длинные имена сокращаются многоточием.

Активная реплика выделяется целиком светло-серым `#E9ECEF`, без внутренней серой плашки и без инверсии текста. Уменьшены верхние отступы реплик и высота заголовка участника. Сообщение об отсутствии речи размещено после заголовка «Стенограмма».

Плеер использует векторные play/pause и fast rewind/forward вместо текстовых символов. Значки расположены по центру элементов управления, у перемотки подпись «5 с». Иконка приложения использует общий оранжевый ресурс. Растровые фрагменты референсов не используются.

## Сообщения и ввод

Сообщения операций отображаются коротким Android Toast и сразу очищаются из состояния контроллера через `clearMessage()`. Отмена экспорта не оставляет постоянную плашку при переключении экранов. Регрессионный тест проверяет очистку, замену слушателя и повторную выдачу такого же сообщения.

Поле поиска поддерживает обычный Unicode-ввод и передаёт клавиатуре языковую подсказку `ru-RU,en-US`. В Gboard тестового эмулятора исходно был включён только English (US); дополнительно включён «Русский (Россия)». Эта настройка относится к эмулятору, а не к APK. Язык переключается через кнопку смены языка или удержание пробела.

## Проверка

- `assembleDebug`, `testDebugUnitTest` (72 теста, без ошибок), `lintDebug` — успешно; Lint содержит предупреждения, ошибок нет.
- В Medium Phone API 37 проверены главная и библиотека, поиск с отдельным возвратом и очисткой, русская раскладка Gboard, выбор и долгое нажатие, открытие стенограммы, воспроизведение с целостной подсветкой, отсутствие речи, отмена экспорта и исчезновение уведомления.
- Проверены крупный шрифт и альбомная компоновка; исходные настройки размера шрифта и поворота восстановлены.
- Полный прогон качества ASR/диаризации на экспертных записях в рамках дизайна не выполнялся.

APK и скриншоты сохранены вне репозитория в `../design-review/v3/`. Изменения локальные, не опубликованы.
