# Тёплый интерфейс Android

Обновление на ветке `feature/orange-ui-refresh` с интеграцией GitHub main `503d623` (7 ноября 2026).

Главный экран использует тёплый белый фон, выразительный заголовок и оранжевую сферу, нарисованную Canvas. Все иконки — векторные ресурсы. Растровые фрагменты присланных референсов не используются. Карточки показывают состояние, а для готовых стенограмм — длительность, количество реплик и участников. Готовая карточка открывается целиком по нажатию.

Стенограмма сохраняет переход по реплике, подсветку текущего фрагмента, плеер, переименование и JSON-экспорт. Имена участников прокручиваются горизонтально; у кликабельных имён высота 48 dp. В альбомном режиме главного экрана скрыт вводный блок, а кнопки импорта и записи расположены рядом. Экран записи прокручивается; при крупном шрифте кнопки паузы и завершения располагаются вертикально.

При выборе взаимодействий изучены первичные материалы Google Recorder:
- https://support.google.com/pixelphone/answer/16269004?hl=en
- https://research.google/blog/who-said-what-recorders-on-device-solution-for-labeling-speakers/

Проверки: `assembleDebug`, `testDebugUnitTest` (71 тест, без ошибок), `lintDebug` — успешно. Lint содержит предупреждения, включая существующий запрет поворота RecordingActivity и неиспользуемые ресурсы; ошибок нет.

Ручная проверка на Medium Phone API 37: библиотека с сохранёнными записями, стенограмма, запуск реплики и пауза, запись с микрофона, пауза/завершение/предпрослушивание, поиск без результатов, выбор записи без удаления, шрифт 130%, альбомная ориентация. Созданная для проверки запись удалена. Настройки шрифта и поворота восстановлены.

Это проверка интерфейса и существующих действий. Полный прогон качества ASR и диаризации на трёх экспертных записях в рамках обновления дизайна не выполнялся. Сохранённая в эмуляторе тестовая стенограмма используется только для проверки интерфейса.

APK и скриншоты находятся в соседнем с репозиторием каталоге `../design-review/`. Изменения не опубликованы в удалённой ветке.
