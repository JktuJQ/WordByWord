# Проверка точности ASR

30 русских телефонных фраз из [PolyAI MINDS-14](https://huggingface.co/datasets/PolyAI/minds14),
`ru-RU`, единственный split `train`, ревизия `40ce77cb32a384e4d50a568e1ec39ac804019d33`.
Индексы равномерно распределены по 539 записям: `round(i * 538 / 29)`, i=0…29.
В выборке 14 тематик, 272,7975 с аудио. Отбора по результатам ASR нет.
Мы не дообучали модель и не подбирали параметры по этой выборке.

`audio.zip` (2,1 МБ) содержит все выбранные WAV. Телефонный μ-law декодирован
в PCM16 mono без изменения частоты 8 кГц; в 16 кГц переводит Android-приложение.
`manifest.json` содержит исходные пути, эталоны из поля `transcription` и SHA-256
исходных/декодированных файлов. Тексты оставлены без ручных исправлений.

Автор набора: PolyAI / Daniela Gerz et al., *Multilingual and Cross-Lingual
Intent Detection from Spoken Data* (2021), [статья](https://arxiv.org/abs/2104.08524).
Лицензия [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/).
Преобразования этой копии: выбор 30 примеров, декодирование WAV и упаковка.

## Метрики и запуск

### Результат

Основное приложение, GigaAM v2 int8 + Silero VAD, Android API 36 / x86_64,
Pixel 6 AVD на Ryzen 5 5600H, без сети. Модель и параметры не менялись после
получения этой выборки.

| Метрика | Значение |
| --- | ---: |
| WER | **13,63%** (59 ошибок / 433 слова) |
| Замены / удаления / вставки | 37 / 8 / 14 |
| CER без пробелов | **8,21%** (185 ошибок / 2252 символа) |
| Полностью совпавшие фразы после нормализации | 13 / 30 |
| Длительность / обработка | 272,7975 с / 169,762 с |
| RTF | **0,622** |

Все 30 фраз включены в результат, ошибок выполнения не было.
Пары текстов и ошибки каждой фразы: [results.json](results.json).

Вся обработка выполняется в основной Android-сборке, включая VAD и декодер,
при отключённой сети. Модели/параметры совпадают с [#5](../../docs/asr.md).
Для каждой фразы модели загружаются заново, поэтому RTF включает этот расход.

```sh
./gradlew assembleDebug assembleDebugAndroidTest
python3 benchmarks/asr/evaluate.py run --adb /путь/к/adb --serial emulator-5554
python3 benchmarks/asr/evaluate.py score
```

Предварительно установить основной APK и модели по инструкции #5.
Скриптов скачивания датасета здесь нет: всё аудио уже в архиве.

- WER = (замены + удаления + вставки слов) / число слов эталона.
- CER — такое же расстояние по символам, без пробелов.
- Нормализация обеих сторон: NFKC, нижний регистр, `ё→е`, пунктуация заменяется
  пробелами, повторные пробелы сжимаются. Числа в слова не преобразуются.
- Итоговые WER/CER — суммы ошибок по корпусу, делённые на суммы длин эталонов,
  а не среднее процентов по фразам. Пустой ответ учитывается как удаления.
- RTF = суммарное время обработки / суммарная длительность аудио.

В `results.json` сохраняются метрики и пары «эталон / распознано» для всех фраз.
Сырые Android-отчёты и распакованное аудио остаются локальными.
Это небольшой контроль телефонной речи. Качество разметки берётся из исходного
набора; отсутствие этих записей в обучении GigaAM не подтверждено. Встречи,
одновременная речь и диаризация требуют отдельной оценки.
