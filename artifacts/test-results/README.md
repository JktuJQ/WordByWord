# Проверка на телефоне

Владелец подтвердил успешную установку и работу приложения на телефоне.
Параметры устройства, перечень проверенных сценариев и метрики пока не записаны.
План проверки — в [docs/build.md](../../docs/build.md#приёмка-на-телефоне).
Измерения на эмуляторе приведены в [evaluation/README.md](../../evaluation/README.md) и [docs/processing.md](../../docs/processing.md).

В отчёте укажите:

- commit и SHA-256 APK;
- модель телефона, Android и RAM;
- запись, её длительность и версии моделей;
- время обработки, RTF и потребление памяти;
- результаты проверки текста, диаризации и таймкодов;
- проверенные сценарии и найденные дефекты.

Исходные контрольные записи находятся в `evaluation/fixtures/`.
